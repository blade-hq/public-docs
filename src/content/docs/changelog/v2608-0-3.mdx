<div class="release-heading"><span class="release-badge stable">正式版</span><time>2026.08.12</time></div>

<p class="article-deck">这是 2608 交付线的一次集中更新，覆盖软件工厂、接入 SDK、会话记忆和浏览器执行链。</p>

## 智能应用开发

新增“开发智能应用”技能，三种接法各带一份可运行模板；`frontend-design` 成为内置技能，沙盒预装离线网页字体。模式 3 改用官方聊天组件，模型密钥可以通过登录自动配置。

<img class="article-shot" src="../../images/releases/v2610.0.0-beta.0/software-factory.png" alt="软件工厂项目创建页面" />

## SDK 与会话

`agent-react` 聊天组件完成分层，增加标准 OpenAI 协议的纯 LLM 模式。React 与 Python SDK 补上零配置接入方法，会话回放重新回到界面并开放给 SDK。

共享记忆可以按用户开启或关闭，默认不向其他用户开放。会话小结会带上本轮产生的文件和网址；长任务结束后，界面会提醒把稳定流程沉淀成 Skill。

## 浏览器、技能和检索

- 浏览器镜像默认启用，沙盒新标签页重新设计；带宽按观看人数分配。
- Chrome CLI 增加原生 `select` 命令，修复日期输入框和隐藏元素等待问题。
- 联网检索切换到 Exa，配置从环境变量移到管理界面。
- `browser` / `browser-control` 更名为 `builtin-browser` / `browser-extension`。

## 升级注意

浏览器镜像总开关已删除，旧配置不会继续生效。检索配置需要在界面中重新确认。该版本没有接口协议破坏性变化，接入方仍应按 `GET /api/version` 返回值固定 SDK 版本。
