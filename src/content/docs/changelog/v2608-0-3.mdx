<p class="article-deck">该版本与 <code>v2608.0.3-beta.1</code> 是同一份代码。相对上一个主线正式版 <code>v2608.0.1</code> 共 28 个提交；<code>v2608.0.2</code> 是独立回移版本，其修复内容已在 main 线上。</p>

## 影响面

浏览器镜像总开关已删除，旧配置不再生效；联网检索切换到 Exa，原环境变量配置需要在管理界面重新确认。接口协议没有破坏性变化。

## 变更

### 智能应用开发与 SDK

新增「开发智能应用」Skill 和三种可运行模板，`frontend-design` 成为内置 Skill。React 聊天组件分层并加入标准 OpenAI 协议的纯 LLM 模式；JavaScript 与 Python SDK 补齐零配置接入方法，会话回放重新进入 SDK 和界面。

### 会话、记忆与权限

新增会话控制台；共享记忆可按用户启停，默认不向他人开放。会话小结带上文件和网址产物，历史回溯和导出入口恢复。被吊销的 PAT 可以重新补发，普通用户也能查看模型服务地址。（#1676、#1677、#1657、#1658）

### 浏览器、技能与检索

- 浏览器镜像默认启用；新标签页、标签栏、带宽和录屏清晰度调整。
- Chrome CLI 加入原生 `select`，修复日期输入、隐藏元素等待和浏览器扩展鉴权。
- `browser` / `browser-control` 更名为 `builtin-browser` / `browser-extension`。
- 联网检索改用 Exa，配置入口移到界面。

### 界面和运行时修复

侧栏折叠、拖宽把手、看板对话归属和流式滚动做了整理；预览页不再因为选择界面内容而切代理。PocketBase 的部署指导改为默认单容器。

## 前置条件

无新增组件版本要求。请记录原有联网检索配置，升级后在界面中重新填写并测试。

## 升级步骤

1. 将主应用镜像改为 `v2608.0.3` 后重启。
2. 安装 `2608.0.3` 版 JavaScript 或 Python SDK。
3. 在管理界面确认 Exa 检索配置；沙箱镜像无需更新。

## 回滚方式

回退到 `v2608.0.1` 镜像与 SDK。本版没有数据结构迁移。若此前使用 `v2608.0.2` 的默认令牌修复，回滚前应确认目标版本仍满足当前 Blade OAuth 部署要求。

## 已知限制

内置 `user-browser` Skill 的 `SKILL.md` 仍超过 Read 的 20000 字符阈值，智能体直接读取时只能看到文件过大的提示。
