<p class="article-deck">这一版在 <code>v2608.0.0</code> 上加入九项改动，主要落在智能应用开发、浏览器镜像和长任务收尾。</p>

## 变更

### 智能应用开发

- 新增「开发智能应用」Skill，三种接法各带一份可运行模板。（#1624）
- `frontend-design` 加入内置 Skill，沙箱预装离线网页字体。（#1633）
- 智能应用组件可直接复制，并补上 AI 回调自有系统的接法。（#1637）

### 浏览器与对话

- 重做沙箱新标签页，修复浏览器镜像的标签栏和带宽问题。（#1626）
- 修复原生日期输入框逐字错位和等待隐藏元素不结束的问题。（#1629）
- 长任务结束后会提示把稳定流程整理成 Skill，并放宽小结校验。（#1628）

### 界面与 Skill 开发

看板对话归到发起它的会话下，侧栏折叠和拖拽入口也做了调整。（#1631、#1632）`develop-skill` 在写入 `SKILL.md` 前会先复述需求，请用户确认。（#1635）

## 前置条件

无。

## 升级步骤

把镜像与 SDK 更新到 `2608.0.1` 后重启服务。沙箱镜像是否需要刷新，以部署包内的镜像清单为准。

## 回滚方式

切回 `v2608.0.0` 镜像与同版本 SDK。

## 已知限制

原始 Release 没有单独列出已知限制；升级前仍应在测试环境验证软件工厂模板和浏览器镜像。
