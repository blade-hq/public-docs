<div class="release-heading"><span class="release-badge beta">预发布</span><time>2026-08-13</time><span class="release-risk danger">破坏性变更</span><span class="release-risk">需同步 Blade Hub</span></div>

<p class="article-deck">模板 ID 从单段改为 <code>&lt;owner&gt;/&lt;slug&gt;</code>，Blade Agent 与 Blade Hub 之间没有兼容窗口。发布该版本时，Blade Hub 对应分支尚未发版，因此不能直接用于生产升级。</p>

## 部署前必读

- 新 Blade Agent + 旧 Blade Hub：模板详情、素材和下载全部返回 404。
- 旧 Blade Agent + 新 Blade Hub：响应缺少 `id` / `owner`，前端生成错误路由。
- Blade Hub 侧对应分支为 `feat/software-factory-template-user-space`，发布本预发布版时仍未出正式版本。先确认目标环境已包含该改动。
- Blade Hub 的 `presets.yaml` 还要声明模板组织并配置 `repo_prefix: template--`，否则匿名用户和非组织成员看不到预置模板。

## 变更

### 软件工厂模板

模板列表、详情、素材和下载四条代理路径统一交换凭证并透传用户身份；API Key 与普通 JWT 走同一套回退逻辑。模板路由、AppDevPage 和侧栏搜索改用两段 ID。（#1716）

### 身份与权限

管理员判定改为跟随 Blade OAuth 的身份声明，首个登录用户不再自动成为管理员。（#1704）升级后应检查管理员账号与组织配置，不能再依赖登录顺序授予权限。

### 会话、搜索与统计

- 新增轻量渲染模式，成果汇总重新整理。（#1694、#1697）
- 新增用户级全局搜索，用户身份和工作偏好进入上下文。（#1709、#1711）
- 已发布应用加入访问统计，修复统计生命周期；Blade Agent 增加效果反馈埋点和跳转。（#1707、#1710、#1712、#1699）

### 浏览器与 CLI

浏览器手动模式会避让自动操作，标签页闲置后冻结，CLI 可以主动关闭浏览器释放资源；历史前进和后退不再依赖导航事件，空闲冻结节流窗口也已修复。（#1700、#1696、#1703）

## 内部变更

三个 CLI 移到 `builtin/clis/`。（#1689）自定义沙箱镜像或脚本如果引用旧路径，升级前必须调整。

## 前置条件

Blade Hub 必须含模板用户空间改动，并完成 `presets.yaml` 配置。还要确认管理员身份由 Blade OAuth 正确声明。

## 升级步骤

1. 在隔离测试环境部署带模板用户空间改动的 Blade Hub；若没有可确认的版本，不要继续。
2. 验证模板仓库采用 `<owner>/<slug>`，预置模板组织和 `repo_prefix` 配置正确。
3. 部署 `v2610.0.0-beta.1`，再验证模板列表、封面、详情、下载、管理员权限和全局搜索。
4. SDK 如需更新，使用与服务端相同的 `2610.0.0-beta.1` 版本。

## 回滚方式

Blade Agent 与 Blade Hub 必须成对回滚到升级前的组合；只回滚其中一个会落入上面的双向失败状态。回滚后复核模板路由和管理员权限。

## 已知限制

发布时没有可引用的 Blade Hub 正式版本，因此这份预发布版只适合协同验证。模板 ID 变化没有兼容窗口。
