<div class="release-heading"><span class="release-badge stable">正式版</span><time>2026-08-07</time></div>

<p class="article-deck">从这一版起，Blade Agent 使用 CalVer：<code>YYMM.MINOR.PATCH</code>。<code>2608</code> 表示 2026 年 8 月开始的交付线，历史 <code>1.x</code> 停止发布。</p>

## 影响面

SDK 从 `1.1.1` 跳到 `2608.0.0` 只是编号变化，事件协议没有因此改变。写死 `^1.1.0` 版本范围的接入方不会自动升级，需要手工调整依赖版本。

## 主要变更

### 软件工厂与应用上线

项目支持空白、模板和已有代码三种导入方式；文件变更进入版本记录，Git 面板和项目删除入口也一并调整。应用端口改为租约制，端口归属以沙箱内实际运行的进程为准。（#1457）

### 对话、技能与协作

执行期增加任务清单和进度看板；会话侧栏、文件卡片和后台任务入口重新整理。运行中安装的技能会同步到 daemon，会话可获得内置技能快照。多用户协作加入按组织过滤的成员分配。

### SDK 与运行边界

JavaScript 聊天组件支持 `theme`，并提供自包含样式。运行时不再限制智能体只能访问工作区路径，它可以访问进程权限允许的绝对路径。（#1446）

`blade deploy` 已废弃，应用上线统一走 deploy Skill。（#1619）

## 内部变更

该版本相对 `v1.1.8` 累计 197 个提交，其中包含依赖、测试、性能和界面整理。详细提交号保留在内部仓库。

## 前置条件

无新增必填环境变量。确认接入方可以把 SDK 从 `1.x` 改到 `2608.0.0`。

## 升级步骤

1. 将 Blade Agent 镜像 tag 改为 `v2608.0.0` 并重启。
2. 请求 `GET /api/version`，按返回的 `version` 安装同版本 SDK。
3. 不需要更新沙箱镜像，本版继续使用 `sandbox-v0.0.29`。

## 回滚方式

切回升级前使用的 `1.x` 镜像并重启。本版本没有不可逆数据迁移。

## 已知限制

依赖范围仍写成 `^1.1.0` 的应用不会自动拿到 2608 版本；编号切换后也不能再发布新的 `1.x` 版本。
