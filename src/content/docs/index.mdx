Blade Agent 是一个可私有化部署的智能体运行时。它在沙箱里执行命令、驱动浏览器、调用已注册的技能，并通过 REST 与 Socket.IO 把会话、文件和工具能力开放给其他应用。

这套文档说明怎么部署和使用 Blade Agent，也覆盖智能体开发、SDK 接入、接口参考与运维。想了解设计取舍，请看 [Blog](./blog/)；想判断是否该升级，请看 [更新日志](./changelog/)。
