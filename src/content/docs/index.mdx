## 不是聊天框的另一种皮肤

Blade Agent 的工作对象是你的文件、网页和系统。它会把任务拆开，在沙盒里执行命令，必要时打开浏览器核对结果，再把可下载的文件、代码或网址交回来。你能看到它做了什么，也能在关键步骤叫停或改方向。

<div class="capability-grid">
  <article><span>WORK</span><h3>让智能体接手完整任务</h3><p>上传资料，指定目标。长任务会拆分执行，完成后给出结果和产物，而不是只留下一段建议。</p></article>
  <article><span>BUILD</span><h3>从一句话开始做软件</h3><p>软件工厂把需求、文件和 Git 项目接到同一条开发链路，前端、后端和智能体能力可以一起生成。</p></article>
  <article><span>CONNECT</span><h3>把能力接进现有产品</h3><p>使用 React、Vue、Python SDK 或 REST / WebSocket API，把聊天、会话、文件和技能能力嵌入自己的应用。</p></article>
  <article><span>OWN</span><h3>部署在自己的环境里</h3><p>模型、沙盒、OAuth、监控和数据路径都能配置。文档覆盖单机、Docker 和盒子环境。</p></article>
</div>
