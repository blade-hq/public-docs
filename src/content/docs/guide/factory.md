> 旧版文档中的 `http://<host>:8020/studio/vibe-coding` 已不再是软件工厂入口，该地址现在打开的是「方案工作区」（`/studio/prod_solution`）。

## 什么是软件工厂

软件工厂是面向软件开发场景的完整工作台，支持从创建项目到发布应用的全流程。即使你不是专业开发者，也可以通过与智能体对话来完成软件开发工作。

## 新建项目

页面顶部是项目列表（显示当前在线项目数），下方是创建区，支持三种进入方式：

- **一句话生成**：在「你想搭建什么？」输入框里描述目标，智能体直接创建并开始开发
- **模板**：从预设模板快速启动
- **导入项目**：导入已有代码，或从文件夹、Git 地址继续开发

创建区下方会列出最近项目，点击即可回到对应项目继续对话。

## 项目会话管理

每个项目有独立的对话面板。智能体自动感知项目上下文（代码、文件结构、历史修改等），你可以直接描述需求，智能体会在当前项目中操作。

## 任务看板

可视化管理开发任务，支持任务状态流转：

- **待办** → **进行中** → **完成**

支持任务的汇报与审核流程。任务看板是否在项目内出现，取决于项目类型与所用解决方案，以项目内实际界面为准。

## 代码编辑与预览

集成代码编辑器，支持：

- 在线编辑代码文件
- Git 彩色 diff 预览，直观查看每次修改的变更内容

Git 仓库托管在 Gitea（`http://<host>:30030`）。Gitea 使用平台统一认证登录：在 Gitea 登录页点「使用「blade」登录」，不要用平台账号密码填 Gitea 自带的登录表单——两者账号体系不通用。

## 应用发布

开发完成后，可以将应用直接发布，无需手动部署。

## 智能体配置

支持项目级的智能体配置管理，针对不同项目可以使用不同的智能体设置。

## 服务探测

软件工厂会自动检测应用服务端口的活跃状态，帮助你了解应用是否正常运行。
