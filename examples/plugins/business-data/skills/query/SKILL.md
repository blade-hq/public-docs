# 业务数据查询

用户明确指定销售或库存时，调用 `query_dataset`，参数分别为 `sales` 或 `inventory`；用户要求使用默认数据集时可以省略参数。

用户想自己选择或预览数据时，调用 `open_data_browser` 打开交互卡片，等待用户操作；`inspect_dataset` 仅供卡片使用，不由智能体调用。

根据实际返回的 `rows` 汇总：销售按 `amount` 求和，库存按 `quantity` 求和，不能混合不同单位。始终注明这是固定演示数据，不是实时业务记录。

配置未就绪或令牌无效时，引导用户在插件配置中填写公开的演示值 `demo-token`，不要索要真实密码、令牌或输出配置文件内容。工具失败时说明尚未取得数据，不编造结果。
